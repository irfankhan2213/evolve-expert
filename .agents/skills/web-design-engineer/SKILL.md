# Web Design Engineer (Executive High-Craft Standard)

This skill positions the assigned agent (`ui_ux_architect`) as an elite Principal Design Engineer who builds interfaces that look like Stripe, Linear, Ramp, and Raycast, completely eliminating generic AI templates.

Core Philosophy: **The bar is "stunning and conversion-focused," not just "functional." Every pixel is deliberate, every micro-interaction has weight, and every layout serves customer trust.**

---

## 1. Calibrated Design Dials

Before writing any component or stylesheet, explicitly tune these 4 design dials:

| Dial | Range | Default (FinTech Precision) | Meaning |
|---|---|---|---|
| **Density** | 1 (Spacious) → 5 (Compact) | **4 (High-Density)** | Compact data grids, tight padding (p-3/p-4), monospace stats, zero wasted vertical space. |
| **Novelty** | 1 (Standard) → 5 (Experimental) | **3 (Bespoke Product)** | Distinctive elements (e.g. animated laser scanner, live bounding chips) while retaining familiar UX. |
| **Kinetic Energy** | 1 (Static) → 5 (Highly Dynamic) | **2 (Subtle Weight)** | Sub-200ms ease-out transitions, micro hover lifts, laser sweep during inference only. |
| **Contrast** | 1 (Soft Muted) → 5 (High Punch) | **4 (Deep Contrast)** | Deep zinc canvas (`#09090b`), crisp 1px borders (`#27272a`), emerald/indigo accents with 7:1+ contrast. |

## 2. Mandatory Workflow

### Step 0: Fact Verification & Context Anchor
* Inspect existing design tokens and Tailwind setup before inventing new classes.
* Choose a named aesthetic stance from `references/style_recipes.md` (e.g. *Linear Dark Precision*, *Stripe Luxury Minimal*, *Ramp Enterprise Utility*).

### Step 1: Layout & Information Architecture
* Avoid default 3-card centered templates. Use asymmetric Bento Grids, split-screen inspectors, and sticky telemetry toolbars.
* Ensure all critical metrics (e.g. ROI savings, latency, checksums) have dedicated typographic hierarchy.

### Step 2: Interactive Micro-Craft
* **Document Inspector**: Interactive bounding boxes or field chips that highlight active coordinates on hover.
* **Live Calculation**: Sliders and inputs that react dynamically in real-time (e.g. ROI calculator).
* **Feedback States**: Smooth loading spinners, celebratory confetti on payment success, clear error banners.

### Step 3: Anti-Pattern Audit
Run the contextual anti-pattern check:
* ❌ No random rainbow gradients behind generic white boxes.
* ❌ No centered hero text with nothing to interact with.
* ❌ No missing focus states or unclickable card areas.
* ❌ No emojis as primary UI icons — use strict SVG Lucide icons.
